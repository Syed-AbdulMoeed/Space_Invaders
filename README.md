## Space Invaders

A polished, Python-based implementation of the classic arcade shooter. This project leverages the **Pygame** library to recreate the iconic "defend Earth" gameplay with smooth mechanics and responsive controls.

---

### 🚀 Key Features
* **Classic Gameplay:** Wave-based alien progression and shield mechanics.
* **Dynamic Scoring:** Real-time score tracking and high-score persistence.
* **Optimized Performance:** Efficient sprite handling for smooth 60 FPS gameplay.
* **Modern Touches:** Integrated sound effects and sleek UI elements.

---

### 🛠 Tech Stack
* **Language:** Python 3.x
* **Library:** Pygame

---

### 📦 Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Syed-AbdulMoeed/Space_Invaders.git
    cd Space_Invaders
    ```

2.  **Install dependencies:**
    *(Ensure you have Python installed)*
    ```bash
    pip install pygame
    ```

3.  **Run the game:**
    ```bash
    python main.py
    ```

---

### 🎮 Controls
| Action | Key |
| :--- | :--- |
| **Move Left** | Left Arrow / A |
| **Move Right** | Right Arrow / D |
| **Shoot** | Spacebar |
| **Quit** | Esc |
